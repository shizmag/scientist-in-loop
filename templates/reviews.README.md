# Reviews

Store manuscript estimate reports here as timestamped directories:

```text
.sil/reviews/
  README.md
  review_<stamp>/
    meta.yaml
    report.md
    report.json
    personas.yaml   # optional L1 panel config
```

Produced by `sil paper estimate --write` or MCP `sil_review` with `write=true`.

**Read-only artifacts** relative to `paper_draft.tex` — scores are advisory.
