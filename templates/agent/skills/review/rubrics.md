# Quality rubrics (0–100)

Use integer scores. Anchor examples (not quotas):

| Score band | Meaning |
|------------|---------|
| 90–100 | Exemplary; ready for top venue with polish only |
| 80–89 | Strong; minor fixes |
| 65–79 | Solid core; clear revisions needed |
| 50–64 | Substantial gaps; major revision |
| 0–49 | Fundamental flaws; reject or rewrite |

## Dimensions

1. **significance** — Why the field should care  
2. **novelty** — Non-incremental contribution  
3. **methodology** — Design validity, controls, metrics  
4. **clarity** — Structure, prose, figures  
5. **related_work** — Fair positioning, key cites present  
6. **reproducibility** — Enough detail to reimplement / data access  
7. **ethics** — Overclaims, dual-use, human subjects, disclosure  

## Decision from overall mean

≥80 accept · 65–79 minor_revision · 50–64 major_revision · <50 reject  

If any Devil’s Advocate **CRITICAL** is unresolved, do not report bare accept.
